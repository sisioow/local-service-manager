# 本机服务管理台

启动：`./start.sh`，打开 http://127.0.0.1:9990 。首次安装需要 Python 3 和网络。

- 自动列出当前用户有权限读取的 TCP 监听进程，显示端口、监听地址、可执行文件、工作目录和启动参数。
- 支持搜索、多选、批量关闭或重启，每 5 秒刷新。
- 关闭先发送 SIGTERM，4 秒未退出则发送 SIGKILL；影响进程全部端口。
- 重启前读取原参数、目录和环境变量，读取失败则保留原进程。新进程输出写入 `logs/restart-原PID.log`。启动后存活不代表应用就绪，请检查刷新后的端口和日志。
- 仅绑定本机地址，使用 Host 检查和随机操作令牌；保护自身及父进程，操作前校验进程创建时间。
- 不提升权限。由 launchd、Docker、开发监视器或其他管理器托管的服务，应优先通过原管理器控制；直接关闭可能触发自动重启。列表不包含未监听端口的后台任务和 UDP 服务。
- 已关闭的进程会从列表消失；重启操作针对仍在运行的服务。

验证：`.venv/bin/python verify.py`（使用临时端口 19990）。
